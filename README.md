# ระบบแจ้งสิ่งของชำรุด — โรงเรียนดอนศาลานำวิทยา

เว็บแอปแจ้งของชำรุดพร้อมอัปโหลดรูปภาพ บันทึกข้อมูลลง **Google Sheets** เก็บรูปใน **Google Drive**
และส่ง **อีเมลแจ้งเตือน** ไปยังฝ่ายที่รับผิดชอบโดยอัตโนมัติ ผ่าน Google Apps Script

โครงสร้างไฟล์:
```
donsala-repair-system/
├── index.html              ← หน้าเว็บหลัก
├── style.css                ← ดีไซน์
├── app.js                   ← ตรรกะฝั่งหน้าเว็บ เรียก API ของ Apps Script
├── config.js                ← ใส่ URL ของ Apps Script ตรงนี้
└── google-apps-script/
    └── Code.gs               ← โค้ดฝั่งเซิร์ฟเวอร์ (วางใน Apps Script Editor)
```

## ขั้นตอนติดตั้ง

### 1. เตรียม Google Sheet + Apps Script (ฝั่งเก็บข้อมูล/แจ้งเตือน)
1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น `ข้อมูลแจ้งซ่อม`
2. เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดตัวอย่างทั้งหมด แล้ววางเนื้อหาจากไฟล์ `google-apps-script/Code.gs`
4. แก้ไขตัวแปร `DEPT_EMAILS` ในโค้ดให้เป็นอีเมลจริงของแต่ละฝ่าย เช่น
   ```js
   const DEPT_EMAILS = {
     'ฝ่ายอาคารสถานที่': 'building@yourschool.ac.th',
     ...
   };
   ```
5. กด **Deploy > New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. กด Deploy แล้วอนุญาตสิทธิ์ (authorize) ตามที่ระบบขอ (เข้าถึง Sheet, Drive, ส่งอีเมล)
7. คัดลอก **Web app URL** ที่ได้ (ลงท้ายด้วย `/exec`) เก็บไว้ใช้ในขั้นตอนถัดไป
8. ระบบจะสร้างชีตชื่อ `Reports` และโฟลเดอร์ Drive ชื่อ `DonSala-RepairPhotos` ให้อัตโนมัติเมื่อมีการแจ้งซ่อมครั้งแรก และจะสร้างชีตชื่อ **`รายชื่อ`** ให้อัตโนมัติเช่นกัน (มีแถวตัวอย่าง 2 แถวให้ดูรูปแบบ)

### เพิ่มรายชื่อผู้แจ้ง (บังคับเลือกจากลิสต์)
เปิด Google Sheet ไปที่แท็บ **"รายชื่อ"** (อยู่ด้านล่างถัดจากแท็บ Reports) แล้วพิมพ์ชื่อ-นามสกุลของครู/นักเรียนทีละแถวในคอลัมน์ A ตั้งแต่แถวที่ 2 เป็นต้นไป (แถวที่ 1 เป็นหัวตาราง ห้ามลบ) เช่น
```
ชื่อ-นามสกุล
ครูสมชาย ใจดี
เด็กชายสมหวัง ตั้งใจเรียน ม.1/1
เด็กหญิงมานี รักเรียน ม.2/3
```
เพิ่ม/ลบ/แก้ชื่อได้ตลอดเวลาโดยไม่ต้องแก้โค้ดหรือ Deploy ใหม่ — หน้าฟอร์มจะดึงรายชื่อล่าสุดทุกครั้งที่เปิดหน้าเว็บ ผู้แจ้งจะเลือกได้เฉพาะชื่อที่มีอยู่ในลิสต์นี้เท่านั้น พิมพ์ชื่อเองไม่ได้อีกต่อไป

### 2. ตั้งค่าเว็บฝั่งหน้าบ้าน
เปิดไฟล์ `config.js` แล้ววาง URL จากขั้นตอนที่ 7:
```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

### 3. อัปโหลดขึ้น GitHub
```bash
cd donsala-repair-system
git init
git add .
git commit -m "ระบบแจ้งสิ่งของชำรุด โรงเรียนดอนศาลานำวิทยา"
git branch -M main
git remote add origin https://github.com/<username>/donsala-repair-system.git
git push -u origin main
```
(สร้าง repository เปล่าบน GitHub ก่อน แล้วแทนที่ `<username>` ด้วยบัญชีของคุณ)

### 4. เปิดใช้งานผ่าน GitHub Pages (ฟรี ไม่ต้องมีเซิร์ฟเวอร์)
1. ไปที่ repository บน GitHub > **Settings > Pages**
2. Source เลือก branch `main` โฟลเดอร์ `/ (root)`
3. บันทึก แล้วรอสักครู่ จะได้ลิงก์ เช่น
   `https://<username>.github.io/donsala-repair-system/`
4. แชร์ลิงก์นี้ให้ครู/นักเรียน/เจ้าหน้าที่ใช้งานได้ทันที

## การทำงานของระบบ

- **ผู้แจ้ง**: กรอกแบบฟอร์ม แนบรูป (ระบบย่อรูปในเบราว์เซอร์ก่อนส่ง) → ข้อมูลถูกส่งไปที่ Apps Script → บันทึกแถวใหม่ใน Google Sheet, อัปโหลดรูปขึ้น Drive, ส่งอีเมล HTML แบบมีรูปฝังในเนื้ออีเมลโดยตรง (ไม่ต้องคลิกลิงก์) ไปยังฝ่ายที่เลือกทันที
- **ผู้รับผิดชอบ**: เปิดแท็บ "ผู้รับผิดชอบ" เพื่อดูสรุปจำนวน กรองตามสถานะ เปิดดูรายละเอียด/รูป และกดเปลี่ยนสถานะ (รอดำเนินการ → กำลังดำเนินการ → เสร็จสิ้น) ซึ่งจะอัปเดตกลับไปที่ Google Sheet ทันที
- ข้อมูลทั้งหมดอยู่ใน Google Sheet ของโรงเรียน ดูย้อนหลัง/ทำรายงาน/กรองข้อมูลด้วย Sheets ได้โดยตรง

## วิธีแก้ไขตัวเลือกในแต่ละหัวข้อ

ตัวเลือกทั้งหมด (สถานที่ตั้ง, หมวดหมู่สิ่งของ, ฝ่ายที่รับผิดชอบ, สถานะงาน) กำหนดไว้เป็นตัวแปรลิสต์อยู่บนสุดของไฟล์ `app.js` — เปิดไฟล์นี้ด้วยโปรแกรมแก้ไขข้อความ (Notepad, VS Code ฯลฯ) แล้วแก้ตรงนี้:

```js
const LOCATIONS   = ["ห้องเรียน","ห้องปฏิบัติการวิทยาศาสตร์", ...];  // สถานที่ตั้ง
const CATEGORIES  = ["โต๊ะ/เก้าอี้","ไฟฟ้า/หลอดไฟ", ...];           // หมวดหมู่สิ่งของ
const DEPARTMENTS = ["ฝ่ายอาคารสถานที่","ฝ่ายไฟฟ้า", ...];          // ฝ่ายที่รับผิดชอบ
const STATUSES    = ["รอดำเนินการ","กำลังดำเนินการ","เสร็จสิ้น"];    // สถานะงาน
```

**วิธีเพิ่ม/ลบ/แก้ชื่อ:** พิมพ์ข้อความในเครื่องหมายคำพูด `" "` คั่นแต่ละรายการด้วยจุลภาค `,` เช่น อยากเพิ่ม "ห้องดนตรี" ในสถานที่ตั้ง ก็พิมพ์ `"ห้องดนตรี",` แทรกเข้าไปในลิสต์ แล้วบันทึกไฟล์ — ไม่ต้องแก้ที่อื่นเลยสำหรับ 3 หัวข้อนี้ ระบบจะดึงไปสร้างเป็นตัวเลือกในฟอร์มให้อัตโนมัติ

**ข้อควรระวังเฉพาะ "ฝ่ายที่รับผิดชอบ":** ชื่อฝ่ายในลิสต์ `DEPARTMENTS` ต้องตรงกับ **ตัวสะกดเป๊ะๆ** กับที่ตั้งไว้ใน `DEPT_EMAILS` ในไฟล์ `google-apps-script/Code.gs` เพราะระบบใช้ชื่อฝ่ายนี้ไปค้นหาอีเมลที่จะส่งแจ้งเตือน ถ้าแก้ชื่อฝ่ายฝั่งใดฝั่งหนึ่งแล้วลืมอีกฝั่ง อีเมลแจ้งเตือนจะไม่ถูกส่งออก (แต่ข้อมูลยังบันทึกลง Sheet ตามปกติ)

**ข้อควรระวังเฉพาะ "สถานะงาน":** ถ้าเปลี่ยนชื่อสถานะ (เช่นจาก "เสร็จสิ้น" เป็น "ซ่อมเสร็จแล้ว") ต้องแก้ 2 จุดเพิ่ม:
1. ในไฟล์ `style.css` หาบรรทัด `.stamp.เสร็จสิ้น{...}` แล้วเปลี่ยนชื่อคลาสให้ตรงกับสถานะใหม่ (สีของป้ายจะผูกกับชื่อสถานะโดยตรง)
2. ในไฟล์ `google-apps-script/Code.gs` ฟังก์ชัน `createReport` มีค่าเริ่มต้น `'รอดำเนินการ'` ตอนสร้างรายการใหม่ ต้องให้ตรงกับชื่อสถานะแรกในลิสต์

**ระดับความเร่งด่วน** (ทั่วไป/ปานกลาง/เร่งด่วน) ฝังอยู่ในโค้ด HTML ของฟอร์มโดยตรง (ในฟังก์ชัน `renderReportView()`) เพราะแต่ละตัวเลือกผูกกับสีเฉพาะ หากต้องการแก้ไข ให้ค้นหาคำว่า `urgency-group` ในไฟล์ `app.js` แล้วแก้ทั้ง 3 บรรทัด `<input>`/`<label>` พร้อมกับแก้สีที่ตรงกันในไฟล์ `style.css` (ค้นหา `lv-ต่ำ`, `lv-กลาง`, `lv-สูง`)

> 💡 ไฟล์ `report-app.html` ที่ใช้ดูตัวอย่างในแชทเป็นไฟล์แยกต่างหาก มีโค้ดชุดเดียวกันฝังอยู่ในตัวเอง ถ้าต้องการให้หน้าตัวอย่างตรงกับของจริง ต้องแก้ไขคู่กันทั้งสองไฟล์

## สีสันของธีม (เทา–เหลืองทอง)

ธีมสีอิงจากสีประจำโรงเรียน (เทาเข้ม + เหลืองทอง) และเพิ่มสีสันด้วยป้ายหมวดหมู่/ฝ่ายที่ให้สีต่างกันอัตโนมัติ (สุ่มจากชื่อ ไม่ต้องตั้งเอง) เพื่อให้สแกนรายการได้ไวขึ้น ปรับสีหลักได้ที่ด้านบนของไฟล์ `style.css`:

```css
:root{
  --ink:#2A2A2E;        /* เทาเข้ม (สีข้อความหลัก/แถบเมนู) */
  --amber:#F2B705;       /* เหลืองทอง (สีเน้นหลัก) */
  --amber-deep:#B8860B;  /* เหลืองทองเข้ม */
  --paper:#F0EEE9;       /* พื้นหลังเทาอ่อนอมทอง */
  --c1 ... --c8;         /* ชุดสีสำหรับป้ายหมวดหมู่/ฝ่าย 8 สี หมุนเวียนอัตโนมัติ */
}
```
เปลี่ยนค่าสี (รหัส HEX) ตรงนี้จุดเดียว สีทั้งเว็บจะเปลี่ยนตามทันที

## ระบบล็อกอิน (จำกัดการแก้ไขสถานะเฉพาะอีเมล @dsl.ac.th)

แท็บ "ผู้รับผิดชอบ" ทุกคนยังเปิดดูรายการได้ตามปกติ แต่ **การกดเปลี่ยนสถานะงานต้องเข้าสู่ระบบด้วยบัญชี Google ที่ใช้อีเมลลงท้าย `@dsl.ac.th` เท่านั้น** ระบบตรวจสอบทั้งฝั่งหน้าเว็บและฝั่งเซิร์ฟเวอร์ (Apps Script ตรวจ token กับ Google โดยตรง) ต่อให้มีคนแก้โค้ดหน้าเว็บก็ยังปลอมอีเมลไม่ได้

### วิธีสร้าง Google Client ID (ทำครั้งเดียว)
1. ไปที่ [Google Cloud Console](https://console.cloud.google.com/) ล็อกอินด้วยบัญชี Gmail ที่ใช้สร้าง Apps Script (บัญชีเดียวกับที่ทำ Google Sheet)
2. สร้างโปรเจกต์ใหม่ (New Project) ตั้งชื่ออะไรก็ได้ เช่น `donsala-repair-auth`
3. เมนูซ้าย ไปที่ **APIs & Services > OAuth consent screen**
   - User Type เลือก **External** แล้ว Create
   - กรอกชื่อแอป (App name) เช่น "ระบบแจ้งซ่อม ดอนศาลานำวิทยา", อีเมลติดต่อ, แล้วกด Save and Continue ไปเรื่อยๆ จนเสร็จ (ไม่ต้องเพิ่ม Scopes หรือ Test users ก็ได้)
4. เมนูซ้าย ไปที่ **APIs & Services > Credentials** > **Create Credentials > OAuth client ID**
   - Application type เลือก **Web application**
   - ที่ **Authorized JavaScript origins** ใส่ URL เว็บของคุณ เช่น `https://<username>.github.io` (ไม่ต้องมี path ต่อท้าย)
   - กด Create จะได้ **Client ID** หน้าตาแบบ `123456-abcxyz.apps.googleusercontent.com`
5. คัดลอก Client ID ไปวางที่ **2 จุด**:
   - `config.js` → `GOOGLE_CLIENT_ID`
   - `google-apps-script/Code.gs` → `GOOGLE_CLIENT_ID` (ต้องเป็นค่าเดียวกันเป๊ะ)
6. Deploy Apps Script เวอร์ชันใหม่ และอัปโหลด `config.js` ขึ้น GitHub

ถ้าต้องการเปลี่ยนโดเมนอีเมลที่อนุญาต (เช่นเปลี่ยนจาก dsl.ac.th) แก้ค่า `ALLOWED_EMAIL_DOMAIN` ที่ทั้ง `config.js` และ `Code.gs` ให้ตรงกัน

## ระบบป้องกันแจ้งซ้ำ
ก่อนบันทึกรายการใหม่ ระบบจะเช็คว่ามีรายการที่ "สถานที่ + จุดที่ตั้ง + หมวดหมู่" เดียวกัน และยังไม่ถูกปิดงาน (ไม่ใช่สถานะ "เสร็จสิ้น") อยู่แล้วหรือไม่ ถ้ามี จะแสดงรายการที่ซ้ำให้ดูพร้อมถามยืนยันก่อนส่งจริง ป้องกันการแจ้งเรื่องเดียวกันซ้ำหลายรอบโดยไม่ตั้งใจ

## หมายเหตุด้านความปลอดภัย

- รูปภาพที่อัปโหลดจะถูกตั้งค่าเป็น "ทุกคนที่มีลิงก์ดูได้" (Anyone with link — view only) เพื่อให้แสดงผลในเว็บได้ หากต้องการจำกัดเฉพาะบัญชีในโดเมนโรงเรียน ให้แก้ `file.setSharing(...)` ใน `Code.gs`
- Web app ตั้งเป็น "Anyone can access" เพื่อให้ทุกคนแจ้งซ่อมได้โดยไม่ต้องล็อกอิน หากต้องการจำกัดเฉพาะคนในโรงเรียน ให้เปลี่ยนเป็น "Anyone within [โดเมนโรงเรียน]" ตอน Deploy
- ทุกครั้งที่แก้โค้ดใน Apps Script ต้องกด **Deploy > Manage deployments > แก้ไข (แก้เวอร์ชัน) > Deploy** ใหม่ ไม่เช่นนั้น URL เดิมจะยังใช้โค้ดเวอร์ชันเก่า
